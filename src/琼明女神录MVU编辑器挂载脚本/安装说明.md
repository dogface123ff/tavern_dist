# 琼明女神录 · MVU 编辑器

这是一个酒馆助手脚本，不需要新增或修改任何酒馆正则。

## 安装

执行 `pnpm build`，打开：

`dist/琼明女神录MVU编辑器挂载脚本/index.js`

在酒馆助手中新建一个全局脚本，例如命名为「琼明女神录 · MVU stat_data 编辑器」，将这个 `index.js` 的**全部内容**直接粘贴到脚本编辑框并启用。

这是单文件自包含脚本：界面、样式和逻辑都嵌入脚本中，不需要 `localhost:5500`、Live Server、网络文件映射，也不会修改酒馆正则。

## 使用

启用脚本后，酒馆右下角会出现一个琼明风格的浮球。点击浮球打开编辑器，可以选择当前楼层、最新楼层或指定消息楼层，查看并编辑 MVU 的 `stat_data` 全部内容。

树状视图支持编辑基础值、布尔值切换、删除字段、添加对象字段和数组项；JSON 视图支持整体编辑。点击「保存到 MVU」后才会写入酒馆变量。
