# AIRP 人物生境 · 人设自检

依据类脑ΟΔΥΣΣΕΙΑ · 三明月《8.15更新//以适配模型出发的，提示词工程人设//人设教程》（AIRP 人物生境写法）整理。完整方法论、正反例与出处见 [references/method.md](references/method.md)——判断边缘情形（某句该属哪层、绝对边界是否成立）时再读，不必每次加载。

## 0. 定位

- **检查写法，不检查文笔**：人物生境写法不自动提高文笔，本 skill 不评价文采。
- **检查，不代写**：只指出问题与修改方向；不替作者发明新的事实（经历、关系、数字）。建议改法中涉及新事实时必须标注"由作者决定"。
- **核心标尺**：人设是"让这个人能够继续生成的最小环境"——事实各归其位、倾向代替答案、留白代替穷举、删减代替证明。人物读到的应当只是一个清楚、连贯、正在生活的人。

## 1. 工作流程

1. **获取人设**：从消息、用户指定文件或世界书条目中拿到待检人设全文。多处存放（描述+世界书+开场白）时全部收集，并注明每段来源位置。
2. **结构定位**：识别人设是否使用了四层标签（`<角色名_基础信息>` / `<角色名_生活结构>` / `<角色名_性情或人物性情>` / `<角色名_场景表达>`）。
   - 有标签 → 按层检查。
   - 无标签的散文人设 → 先按内容职责映射到四层（坐标事实→基础信息；长期接触的现实→生活结构；如何理解与倾向→性情；表达范围→场景表达），在报告中给出建议分层方案后再检查。
   - 只有部分层 → **缺层不是缺陷**（栏目齐全≠人物完整），只检查已有层的质量与层间分工。
   - EJS/模板人设（含 `<% %>`）→ 剥离模板逻辑，按渲染后的纯文本语义检查。
   - 多角色卡 → 逐角色分别执行完整流程。
3. **逐层检查**（第 3 节清单 A–E）。
4. **全局检查与删减**（第 3 节清单 F）。
5. **输出报告**（第 5 节格式）。

## 2. 四层职责（检查的基准）

| 层 | 回答的问题 | 典型内容 |
|---|---|---|
| 基础信息 | 她站在哪里 | 不变的客观坐标：姓名、年龄性别、稳定身份、长期生活区域、识别锚点式外貌、不会失效的关系历史 |
| 生活结构 | 她长期接触和改变什么现实 | 长期工作及真正能做到什么、经验带来的注意点、长期责任、稳定关系群体、常用场所工具、现实限制 |
| 人物性情 | 这份现实经过她以后被理解成什么 | 赋予事情的意义、真正在乎什么及冲突取舍、自我叙事、理解与选择的倾向 |
| 场景表达 | 她怎样走进现场 | 表达的范围与体量、什么使范围变化、情绪的来路与经过、完整身体与环境的使用、自己的行动线 |

判层口诀：**"她为什么在意"归性情；"她这一幕说了什么做了什么"归具体场景（不进人设）；"她通常怎样把在意变成发言与行动、换场景仍成立"归场景表达。**

## 3. 检查清单

每条 = 检查点（典型信号）。🔴=必改，🟡=建议改，🟢=打磨项（分级标准见第 4 节）。

### A. 结构与分工

- **A1 内容放错层** 🟡：性情解释出现在生活结构（"所以她害怕/渴望"）；生活材料细节写在性情里重复展开；表达范围写在性情层却未与倾向连接。→ 建议移层，信息移层优于删除。
- **A2 同一意思多层复述** 🟡：同一段人生/关系在多层以不同措辞重复（如父亲的事实在基础信息与性情各写一遍且都是事实陈述）。→ 只保留最适合承载它的位置；事实归基础信息，该经历形成的理解归性情，两处不重复叙述经过。
- **A3 事实与意义未拆分** 🟢：一句话同时含事实与推断时，未分别放到各自起作用的位置。

### B. 基础信息层

- **B1 事实/推断混淆** 🔴："……令她养成/使她变得/因此她……"式外貌→性格因果。标尺：身高一米八五是事实；"高挑的身材令她养成疏离骄傲的性格"是作者推断——除非该因果确实属于已确定的经历，否则删出本层（可移性情层重写为倾向）。
- **B2 会过期的状态混入静态层** 🔴：信号词"目前／现在／刚／正在／尚未／还处于／暂时"+状态（目前独居、刚刚接任、正在住院、尚未认识 {{user}}、目前只是朋友、正在冷战）。后果：剧情推进后模型反复收到过期信息→地点复位、关系倒退、已结束事件复发。→ 移到开场白/按时间排列的正文历史/剧情阶段记录/动态状态层。不变的历史（"曾获全国冠军"）可留。
- **B3 关系条目写双边当下状态** 🔴："两人彼此／他们相互／双方都"+情感（彼此深爱、都当没发生过）。→ 只写角色自己这一侧（"她信任 {{user}}"式）；双边关系只有已成为故事事实时才能成立。另查：为预留互动而虚构的不存在共同历史。
- **B4 关系篇幅失衡** 🟡：默认把 {{user}} 放在所有关系之上；或刚认识的临时角色占据主要关系栏（应由剧情历史承载）；或重要长期关系反而不写"不会失效的共同历史+长期影响+她仍独立的生活领域"。
- **B5 印象词撑外貌** 🟡："漂亮/清冷/可爱/帅气"等无事实锚点单独使用；把参考图偶然的光线、姿势、表情、服装写成永久特征。→ 换成识别锚点：体态身高、发瞳肤色、面部结构、疤痕义肢等影响生活的身体事实、与身份长期相连的衣着。
- **B6 无效条件信息** 🟢：删除后模型不会对生活/选择/他人态度产生实质误判的细节（惯用饮料、洗发水品牌、房间盆栽数量）。→ 删或留给剧情自然出现。
- **B7 公共设定误入** 🟡：国家制度、学校规定、魔法体系、城市地图 → 世界书。
- **B8 必要坐标缺失** 🟢：姓名/年龄人生阶段/性别/稳定身份/长期生活区域有缺失（只报缺失项，不强制表格形式；世界公共设定能覆盖的项不算缺）。

### C. 生活结构层

- **C1 日程表/物品栏化** 🟡："每天七点起床""房间里摆着十二盆植物"式内容且不影响选择/能力/关系。
- **C2 强行象征** 🟡：每个爱好物件都被解释成性格象征（喜欢车票→解释为对远方的渴望）。后果：制造新的固定意象，模型反复复读。→ 只保留确实连接长期活动、关系或现实选择的。
- **C3 越权解释意义** 🟡：本层大量出现"她害怕/渴望/把 X 理解成 Y"。→ 本层只写事实与事实的连接（长期接触什么、能完成什么、要对什么负责）。
- **C4 与基础信息重复** 🟡：身份已在基础信息一句话说清，本层又散文化扩写同一事实而无新增行动材料。
- **C5 动态剧情误入** 🔴：今天要参加的比赛、刚接到的委托、正在进行的旅行 → 剧情记录层。
- **C6 冗长堆叠** 🟢：基础信息已提供清楚场域、能力与责任时，本层仍大段展开。→ 可极短或并入基础信息；优先重组压缩已有事实而非追加同义解释。

### D. 人物性情层

- **D1 标签堆放未具体化** 🔴：性格形容词列表（温柔、骄傲、开朗、倔强）没有写"在这个人身上具体意味着什么"。标尺：同样是温柔——确信人人值得善待／太熟悉受伤所以不让别人再受伤／习惯照顾所有人却没学会拒绝／好意被用来伤害第三人时立即收回宽容。→ 保留标签，补具体含义与来源方向。
- **D2 唯一答案式写法** 🔴："总会／每次都／一律／都会／便"+固定动作或台词（"她受到质疑时总会冷笑反击"）。→ 改为写什么刺痛她、她在意什么，让模型自行推导动作：参考"她能承认技不如人，却无法容忍别人把她的努力说成侥幸"——由此她可能反驳、可能用下一次胜利回答、也可能对尊敬的强者安静听完批评。
- **D3 绝对词记账** 🟡：清点全文"永远／绝不会／绝不／从没／一定"出现处。真正的绝对边界（人物不可破的底线事实）可保留；其余改倾向词"往往／容易／更愿意／很难／除非"。报告中须列出这份记账。
- **D4 预写台词与结局** 🔴：连边界的具体台词（"只说'白天再来'"）、循环套路（"会一直重复到对方放弃"）、动作序列都写死。绝对边界只授权措辞强度，不授权预写台词。→ 保留边界本身，删预写内容。
- **D5 完整自我剖析** 🔴：可直接搬进小说的成段内心解释（角色随时能说清自己的成长、恐惧与价值观）。后果：复读从动作变成心理旁白——每遇相似事件先内心解释一遍。→ 解释停在根部：写"她需要保留决定自己去留的权利"，不写她看见行程表时联想什么、触碰什么、到哪里平复呼吸。
- **D6 解释悄悄变造事实** 🔴：性情句附带未确定的经历细节（"她不喜欢别人因旧伤怜悯她"→顺笔写出做过什么手术、几年复健、谁全程陪伴）。→ 三层分账：已确定的事实／据此理解的长期性情／留待剧情的空白。空白不是缺陷，保留未完成能减少模型擅自补造往事。
- **D7 {{user}} 依附** 🔴：把 {{user}} 从场景拿走后，人物没有自己的注意、珍惜、厌恶与行动理由；或全篇只写她如何对待 {{user}}，没有她如何面对自己、陌生人、责任、失败、自由、孤独。
- **D8 强行反差拼接** 🟡："表面 X 内心 Y"式隐藏人格；为立体感硬凑反义性格。后果：模型把人物分成几套轮流切换的表演。→ 自然的变化来自处境、关系距离、事情轻重、身体状态与同时在乎的几件事。
- **D9 单场景内容占比过高** 🟡：动作映射（"紧张时攥衣角"）多于跨场景倾向（"她总觉得自己的难处可以再忍一忍，却无法看着别人因她受苦"——后者影响求助、争吵、工作、爱情、危险、愧疚与牺牲）。
- **D10 预写成长结论** 🟡：把剧情尚未发生的觉醒、和解、转变写成已完成状态。
- **D11 堆放小动作显细腻** 🟢：仅为显得细腻而重复堆放的动作，及已被其他句子包含的同义说明。→ 合并。

### E. 场景表达层

- **E1 情绪-动作映射表** 🔴："愤怒时提高音量，悲伤时沉默，紧张时摸头发"式对照表——仍是固定答案。→ 改写表达范围：她平常占多大表达空间、什么使范围扩大收缩或突然改变。
- **E2 演绎指令混入** 🔴："应该充分表现／避免过度克制／增加大动作／需要展示"等工程指令出现在人物描述里。→ 写进世界书的应是自然描述一个人，让表达范围从人物自身生长出来。
- **E3 冗余声明** 🟢：前三层已能支撑表达时的重复内容（"她很主动""她会推进事情"）→ 本层可删短甚至整层省略。
- **E4 纯回应式存在** 🟡：只写她如何回应别人，没有自己的行动线（未完成的工作、正在争取的事、需要照顾的人）。标尺：继续吃完一顿饭、修好一页信同样是正在生活。
- **E5 预演固定结尾** 🟡：写死了某类场景的收束方式。

### F. 全局与删减

- **F1 元内容混入** 🔴：教程术语（"人物生境""提示词""模型""人设"）、栏目说明、施工痕迹、模板占位（尖括号内说明文字、省略号占位）残留在正文中。→ 最终正文不向模型解释方法。
- **F2 动态信息误放** 🔴：关系阶段、当前地点与任务、用户自身资料、平台输出格式要求出现在长期人设中。→ 各归世界书/剧情记录/场景信息模块。
- **F3 采访/小传整段塞入** 🟡：按年份的完整生平、未核定的采访问答原文。→ 稳定客观事实进基础信息、仍在塑造日常的进生活结构、形成的理解进性情；未经作者核定的问答不自动成为人物事实。
- **F4 删减四问（逐段执行，列入报告）** 🟢：
  1. 删除它，模型会认错这个人的身份、处境或长期生活吗？
  2. 删除它，几种场景里的判断与选择会明显失去依据吗？
  3. 它是否只是换一种说法重复已写过的性情？
  4. 它是否只帮模型复现作者脑中某一幕、不能迁移别处？
  两问皆"否" → 删减候选。另问：一个跨场景成立的句子能否替代数个固定动作与台词？
- **F5 小动作绑定检查** 🟡：某动作与某性情被永久绑定（她一紧张就摸耳钉）且全文多处强化。→ 小动作不必清除，要避免的是永久绑定与替代本该说出的话、完成的事。

## 4. 严重度分级

- 🔴 **必改**：会导致模型复读固定答案、剧情状态倒退、心理旁白化、补造事实、收到自相矛盾指令的问题（B1–B3、C5、D1、D2、D4–D7、E1、E2、F1、F2）。
- 🟡 **建议改**：降低人设质量、占用上下文、制造固定意象的问题。
- 🟢 **打磨项**：合并、删减、措辞优化。

没有问题就明确说通过，不为了凑数降级凑报告。

## 5. 报告格式

```markdown
## 人设自检报告：<角色名>

**总评**：通过 ／ 建议修改（N 处必改）／ 需要重整（结构性问题）
**结构识别**：识别到的层与映射（无标签时给出建议分层方案）

### 🔴 必改（N 条）
1. **[层名·规则编号] 规则名**
   - 原文：`引用原句（标注来源位置）`
   - 问题：违反了什么 + 会造成什么后果
   - ✏️ 改法：合规的改写示例（涉及新事实时标注"具体事实由作者决定"）

### 🟡 建议改（N 条）
（同上格式，可适当合并同类）

### 🟢 打磨项（N 条）

### 删减候选
- 逐段四问的结论：可删/可合并清单

### 绝对表述记账
- 清单：出现处 → 真边界（保留）／建议改倾向词（给出替换词）

### 通过项
- 简述哪些方面已符合（如静态动态分离干净、{{user}} 独立性成立）
```

## 6. 给改法建议的守则

1. **不替作者发明事实**：改写示例只示范结构与措辞；其中出现的新经历、关系、数字必须标注"由作者决定"。
2. **示例自身必须合规**：改法不能引入新的唯一答案、预写台词、绝对词滥用——这是最容易犯的错（改着改着又写死一个动作）。
3. **移层优于删除**（删减四问通过的除外）：同一信息在错误的层，优先移动而非丢弃。
4. **留白优先**：不为"完整"补写设定；空白不是缺陷。
5. **保留作者的事实**：所有已确定事实默认有效，只调整位置与措辞强度。
