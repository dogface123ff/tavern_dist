  # 核心指令 (System Meta)
      check:
        - 按照最新消息楼层进行更新mvu变量，切勿胡编乱造
        - 在场角色必须更新，实时更新
变量更新规则:
  地点位置:
    大区域:
      check:
        - 可选值：中州/东央/锦南/南海/北域/浮屿（锦南为失昼城、清梦城、绣文馆所在区域；南海泛指锦南外海）
        - 跨区域移动时更新，固定值：中州/南海/北域/浮屿
        - 切换大区域时，子区域和具体地点必须清空
    子区域:
      check:
        - 进入子区域时填写，如“寒宫剑宗”
        - 名称必须与设定中的子区域名称完全一致
        - 切换子区域时，具体地点必须同时清空为""
    具体地点:
      check:
        - 当角色进入某个具体门派/城镇/地点时填写名称
        - 进入具体地点时填写

  世界:
    当前时间:
      format: ${纪}纪${元}元${年}年·${月}月${日}日${时辰}
      check:
        - 每次事件推进、休息或旅行后更新，保持时间流逝合理
        - 若场景跳转跨度较大，应说明跳跃原因
    在场角色:
      type: |-
        {
          [角色名: string]: {
            穿着衣装: string;
            当前状态: string;
          }
        }
      check:
        - 角色名必须使用角色的完整名字，禁止使用简称或称号（如写"陆嘉静"而非"静儿"，写"裴语涵"而非"语涵"）
        - 穿着衣装要求：古风唯美，简短浓缩，20字以内
        - 必须实时更新，角色离场时移除
  主角:
    境界:
      check:
        - 明确突破或跌落境界时更新
        - 修炼进度达到100时突破，突破后修炼进度归零并更新境界
    修炼进度:
      type: number
      range: 0~100
      check:
        - 闭关修炼: +5~15/次
        - 战斗感悟: +3~8/次
        - 获得天材地宝: +10~20/次
        - 获得前辈指点: +8~15/次
        - 顿悟: +15~30/次（罕见）
        - 受伤/走火入魔: -5~20/次
        - 单次变化绝对值不超过30，除非特殊奇遇
        - 达到100时触发突破，突破后归零并更新境界
    当前状态:
      check:
        - 身体状况、心情、行为变化时更新，一句话描述当前的状态
    所属势力:
      check:
        - 更换宗门或被驱逐时更新
    功法面板:
      主修功法:
        check:
          - 转修功法时更新
      功法重数:
        check:
          - 功法突破时更新
      习得心法:
        type: |-
          {
            [心法名: string]: 心法描述
          }
        check:
          - 获得心法时insert
    储物袋:
      货币:
        金元:
          type: number
          check:
            - 大规模交易，如购置房产。
            - 1金元=100银元=10000铜元，大额换算时需同步增减
        银元:
          type: number
          check:
            - 日常中等交易（丹药、普通材料、住店）: ±10~100/次
            - 市井坊市采购: ±5~50/次
        铜元:
          type: number
          check:
            - 零碎小额消费（小吃、茶水、纸张）: ±1~50/次
            - 出售零碎杂物换钱: +10~100/次
      物品:
        type: |-
          {
            [物品名: string]: {
              分类: string;
              描述: string;
              数量: number;
            }
          }
        check:
          - 分类可选值：丹药/材料/杂物
          - 获取时insert或增加数量
          - 消耗时减少数量，数量为0时自动清除
      装备栏:
        本命武器:
          check:
            - 更换、损毁、重铸时更新
            - 名剑"羡鱼"损毁或易主需特别说明

  关系列表:
    type: |-
      {
        [角色名: string]: {
          修为: string;
          好感度: number;
          关系态度: string;
          重要事件: string;
        }
      }
    check:
      - 新角色首次出场时insert完整信息
      - 重要角色才需要被记录，普通或者npc无需记录
      - 好感度范围-50~200
      - 只有出现明显有好感的行为才能加好感度
      - 好感度区间与关系态度对照：-50~20: 仇敌/生死大仇, -19~0: 厌恶/敌意, 0~20: 冷漠/不相识, 21~50: 相识/普通关系, 51~80: 友好/信任, 81~100: 知己, 101~120: 红颜知己/暧昧， 121~140: 情愫暗生, 141~160: 两情相悦, 161~180: 道侣, 181~200: 不离不弃
      - 红颜知己 != 爱情，不是所有女角色都会爱上用户，红颜知己本身就是美好的终点
      - 从红颜知己到情愫暗生必须有特殊契机（生死与共/长久相处/心动瞬间）
      - 首次遇见女性角色时用 insert 添加到好感度，好感度初始为 0
      - 关系态度随好感度区间同步更新
      - 重要事件在关键剧情后追加记录
      - 对方修为变化时同步更新修为字段

  事件列表:
    type: |-
      {
        [事件名: string]: {
          状态: "未触发" | "进行中" | "已完成" | "已失效";
          阶段: string;
        }
      }
    check:
      - 状态只可按以下方向流转，禁止跳跃或逆转：
      - 未触发→进行中：事件征兆在剧情中实际显现时（如主角身处事件影响范围且异象初现）
      - 进行中→已完成：事件主线彻底落幕、影响消解后
      - 进行中→已失效：事件窗口被错过，或事件被彻底阻止且不会复现
      - 已完成/已失效为终态，永不重开
      - 状态只允许 未触发/进行中/已完成/已失效 四个原词，任何进展描述一律写入阶段字段，禁止写成"进行中（某事）"之类的复合值
      - 表达事件结束或失效只能用 replace 把状态改为已完成/已失效，禁止对事件列表下的键使用 remove
      - 状态变更必须在剧情中有明确依据，禁止无端改动
      - 阶段：状态为进行中时用一句话记录当前进展（如"海妖先锋袭扰外海"），每次重大推进后更新；流转到已完成/已失效时改写为一句结局摘要（如"南宫斩镇天下剑灵，封印重立"），不得清空
